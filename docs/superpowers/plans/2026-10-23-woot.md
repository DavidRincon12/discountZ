# Woot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Woot (Computers, Electronics y Tools) como canal «sin verificar» de EE. UU. por su API oficial.

**Architecture:** Un adaptador `PostsOnlySource` sin orden de ids (como DealNews, ADR 0006) que lee tres feeds por lectura con la clave `x-api-key`. Los canales pasan a recibir las credenciales del ciclo. Migración `0014` registra la fuente.

**Tech Stack:** Python 3.13, httpx, pydantic v2, psycopg 3, pytest.

**Spec:** `docs/superpowers/specs/2026-10-23-woot-design.md`

## Global Constraints

- Dinero en `Money` (USD exponente 2) desde `Decimal` (`json.loads(..., parse_float=Decimal)`); nunca `float`.
- La clave solo en la cabecera `x-api-key`; nunca en logs, `repr` ni excepciones.
- Migración `0014_woot` y ADR `0015` (la `0013` y el ADR `0014` son de 9to5Toys). `SCHEMA_VERSION = 14`.
- Feeds `Computers`, `Electronics`, `Tools`; `[sources.woot]`: `min_pause_s = 1`, `jitter_s = 0`, `max_per_run = 3`, `max_per_24h = 400`, `watch_interval_min = 15`, `search_interval_min = 15`, `max_batch = 1`.
- Textos en español; commits `tipo(woot): …` a nombre de David.

## Review Focus

- Un `OfferId` en dos feeds (Computers y Electronics): una sola publicación (Task 2).
- `SalePrice` con rango (`Minimum` ≠ `Maximum`): se usa el mínimo (Task 2).
- `Condition` «Refurbished» o «Used»: se salta sin contar como roto (Task 2).
- Sin `DISCOUNTZ_WOOT_API_KEY`: la fuente falla como no disponible sin romper el ciclo ni filtrar nada (Task 3).
- Feed con `Items: []`: página vacía, no error (Task 2).

# 9to5Toys Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sumar el RSS de 9to5Toys como fuente `channel` «sin verificar» (`ninetofivetoys`), por casillero.

**Architecture:** Molde de `sources/dealnews.py` (ADR 0006): adaptador `PostsOnlySource` con `ordered_ids=False`; el paso de canales (`app/channels.py`) ya hace duplicados, tema, perfil, mínimos y tope. Precio sacado del título por una función pura.

**Tech Stack:** Python 3.13, defusedxml, pytest + hypothesis, psycopg 3, migraciones SQL.

**Spec:** `docs/superpowers/specs/2026-10-23-9to5toys-design.md`

**Ejecución:** Native (aprobada por David al pedir que se avance solo).

## Global Constraints
- Código de fuente `ninetofivetoys`; nombre visible «9to5Toys»; color `#0F766E`.
- `FEED_URL = "https://9to5toys.com/feed/"`; hosts `{"9to5toys.com"}`; fotos solo de `9to5toys.com`.
- Presupuesto: `min_pause_s = 2`, `jitter_s = 1`, `max_per_run = 1`, `max_per_24h = 200`, `watch_interval_min = 10`, `search_interval_min = 10`, `max_batch = 1`.
- `casillero = True`; `hashtags = ()`; título máx. 200; migración `0013`, `SCHEMA_VERSION = 13`.
- Todo texto en español; commits `tipo(alcance): descripción` a nombre de David, sin trailers.

## Review Focus
- Ahorro tomado como precio («$50 off», «$100 savings», «(Save $350)»): no debe ser el precio. → Task 2, `test_price_from_title`.
- Resúmenes («from $31», «starting at», «under $50»): sin precio. → Task 2.
- Montos con coma o centavos (`$1,379`, `$11.50`): enteros de centavos exactos. → Task 2.
- Noticias sin precio en el feed real: se saltan sin contar como formato roto (`unparsed == 0` en el feed real). → Task 2.
- Enlace o foto fuera de `9to5toys.com`: el enlace invalida el ítem; la foto queda en `None`. → Task 2.

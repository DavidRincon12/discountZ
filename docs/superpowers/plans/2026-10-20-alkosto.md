# Alkosto por Algolia: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** sumar Alkosto (`alkosto`, COP) como tienda con `/seguir`, `/buscar` y rastreo de catálogo leyendo su índice público de Algolia.

**Architecture:** adaptador nuevo `sources/alkosto.py` que cumple `CrawlSource`, con parseo puro (pydantic estricto, `parse_float=Decimal`) y peticiones `POST` a Algolia por `ctx.http`. El rastreo, el dominio y las capas no cambian: solo hay fuente nueva, migración `0007`, configuración, temas y la matriz de `crawl.yml`.

**Tech Stack:** Python 3.13, httpx (`PacedClient`), pydantic v2, psycopg 3, pytest + hypothesis.

**Spec:** `docs/superpowers/specs/2026-10-20-alkosto-design.md` (decisiones K1–K3 en §0.2).

## Global Constraints

- Índice: app `QX5IPS1B1Q`, índice `alkostoIndexAlgoliaPRD`, host `https://QX5IPS1B1Q-dsn.algolia.net`; cabeceras `X-Algolia-Application-Id` y `X-Algolia-API-Key`.
- La clave sale de `https://www.alkosto.com/` con el patrón `apiKey": "<clave>"`, se guarda solo en memoria y nunca va a logs, BD, `repr`, mensajes de error ni fixtures (en fixtures: `CLAVE_DE_PRUEBA`).
- Precio = `lowestprice_double` (COP, exponente 0, entero > 0). Nunca `pricevalue_cop_double` ni `percentagediscount_string`.
- En stock = `instockflag_boolean` y `stocklevel_int > 0`.
- 1.000 resultados por consulta como máximo: una franja con `nbHits > 1000` se parte en dos.
- `external_id` = `objectID` (`^[0-9A-Za-z]{1,40}$`); EAN = `code_string` solo si tiene 8, 12, 13 o 14 dígitos.
- Commits `tipo(alcance): descripción en español`, a nombre de David, sin trailers de IA; texto y comentarios en español, identificadores en inglés.
- TDD estricto: cada cambio de comportamiento parte de una prueba que falla.

## Review Focus

1. Clave rotada a mitad de corrida (Algolia responde 403 «Invalid Application-ID or API key»): se relee la portada una vez y se repite la petición; si sigue fallando, es `HardBlock`. Lo prueba la Task 4.
2. Franja de un solo precio con más de 1.000 productos: no se parte para siempre; se leen los 1.000 y se registra `alkosto_band_truncated`. Lo prueba la Task 5.
3. Producto con `lowestprice_double` ausente, 0 o con decimales: se descarta del barrido sin tumbar la página (no es `ParseError` de toda la página). Lo prueba la Task 3.
4. `url_es_string` que no pasa `SafeUrl` (host ajeno o vacío): se descarta el producto. Lo prueba la Task 3.
5. La clave no aparece en logs ni en el texto de ninguna excepción. Lo prueba la Task 4 con `caplog` y `str(exc)`.

**Interfaces:**

  - Métodos privados `_key(ctx) -> str` (cachea en memoria) y `_post(ctx, path: str, body: Mapping[str, object]) -> bytes`. Ante un 403 con `"Invalid Application-ID or API key"` en el cuerpo, `_post` relee la clave una vez y repite; si sigue igual, `HardBlock(CODE, "api_key")`.

# eBay por la Browse API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agregar eBay (`ebay_us`) como tienda de EE. UU. con `/seguir`, `/buscar` y un job de rastreo que detecta bajadas de una publicación y precios bajos frente al mismo modelo.

**Architecture:** Adaptador `sources/ebay.py` (`CrawlSource`, `auth="oauth_client"`) sobre la Browse API, con el token pedido por `ctx.http`. El dominio gana `model_candidate` (puro) y `AlertKind.MODEL_LOW`; el rastreo gana la consulta de pares por modelo, el descarte por modelo dentro de la fuente y el tope de publicaciones. Migración `0005_ebay`.

**Tech Stack:** Python 3.13, httpx, pydantic v2, psycopg 3, pytest + hypothesis, Pillow (tarjeta).

**Spec:** `docs/superpowers/specs/2026-10-18-ebay-design.md` (aprobado por David el 2026-10-18).

**Skills usadas:** desarrollo-senior, arquitectura-y-datos, calidad-y-seguridad, superpowers:writing-plans.

## Global Constraints

- Código de fuente `ebay_us`, moneda USD, hosts `www.ebay.com` y `ebay.com`, `image_hosts = {"i.ebayimg.com"}`.
- Cabeceras de toda petición: `X-EBAY-C-MARKETPLACE-ID: EBAY_US` y `X-EBAY-C-ENDUSERCTX: contextualLocation=country=US,zip=<ship_to_zip>` (33166 por defecto, URL-encoded como en la prueba).
- Filtro de búsqueda: `conditions:{NEW},buyingOptions:{FIXED_PRICE},deliveryCountry:US,price:[15..],priceCurrency:USD`.
- Vendedor válido: `feedbackPercentage ≥ 98` y `feedbackScore ≥ 100` ⇒ `SellerClass.FIRST_PARTY`; si no, fuera del barrido y `MARKETPLACE` en `/seguir`.
- Precio observado = `price` + envío más barato, en centavos de USD; sin costo de envío conocido ⇒ se descarta. `marketingPrice` nunca se usa.
- `external_id` = `<legacy>` (`^\d{9,15}$`) o `<legacy>V<variación>`; `itemId` de la API = `v1|<legacy>|<variación o 0>`.
- Token: `POST https://api.ebay.com/identity/v1/oauth2/token`, `grant_type=client_credentials`, `scope=https://api.ebay.com/oauth/api_scope`, cabecera `Authorization: Basic <CredentialStore.bearer("ebay")>`. Se renueva a < 5 min de vencer o una vez tras 401. Nunca en logs, BD ni `repr`.
- Modelo: `model_key` = `epid` (`^\d{4,15}$`); `model_candidate` exige n ≥ 5 pares, `price ≤ mediana × (1 − t_bp)` y `mediana − price ≥ min_abs`; `drop_bp ≥ g_bp` ⇒ `PRICE_ERROR`.
- `[ebay]`: `ship_to_zip = "33166"`, `items_per_partition = 75`, `max_items = 150000`, `min_feedback_pct = 98`, `min_feedback_score = 100`, `excluded_roots = [1, 99, 237, 260, 316, 550, 870, 1305, 3252, 10542, 11116, 20081, 45100, 64482, 172008]`.
- `[crawl.ebay_us]`: `max_per_run = 200`, `max_per_24h = 4800`, `hot_share_bp = 4000`.
- Logs con lista blanca: nunca token, query ni cuerpo. Commits `tipo(alcance): descripción en español` a nombre de David, sin trailers de IA.

## Review Focus

1. Token vencido a mitad de una corrida de 45 min: debe renovarse una sola vez y seguir, no abrir el breaker (Task 5).
2. Una página con publicaciones que la BD rechazaría (`external_id` con `|`): nunca debe llegar a `save_catalog_page` (Task 5, prueba de ids).
3. Cuota agotada (429 o `errorId` 2001): la corrida para como `partial` sin abrir el breaker (Task 5 y Task 7).
4. Modelo con exactamente 5 pares y precio igual a la mediana: no alerta (Task 3).
5. Tope de 150 mil alcanzado: las publicaciones ya conocidas se siguen actualizando y las nuevas no se insertan (Task 7).
